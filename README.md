
# Hyprland Dotfiles

My personal **Hyprland** configuration for Linux.

This repository contains the configuration files for my Hyprland environment, versioned with Git to keep the setup organized, maintainable, and easy to evolve.

## Goals

* Keep the configuration clean and organized
* Use Hyprland as the primary desktop environment
* Make the configuration easy to reproduce
* Track changes through Git
* Keep the system simple and customizable

## Structure

```text
hyprland_dotfiles/
├── LICENSE
└── README.md
```

The structure will expand as new configurations are added to the project.

## Installation

Clone the repository:

```bash
git clone https://github.com/csouzape/hyprland_dotfiles.git
cd hyprland_dotfiles
```

Configuration files will be added to the repository as the project evolves.
